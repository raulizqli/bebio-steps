# bebio-steps
Baby tracking application designed to log, store, and analyze infant routines. It captures sleep, feeding, diaper changes, and growth metrics, providing structured data, historical views, and trend analysis through a secure, extensible architecture.

## Product scope (ES)
Aplicacion para registrar tomas, horas de sueno, comidas (cuando aplique), sintomas de enfermedad, enfermedades, medicinas y estado de animo. Debe contar con apps para iOS y Android, mas integracion con Alexa.

## Key capabilities
- Registro de eventos: tomas, sueno, comidas, sintomas, enfermedades, medicinas, estado de animo.
- Apps nativas iOS/Android y skill de Alexa con account linking.
- Registro de padres (uno o ambos) y sistema de invitaciones con codigo para nanny o familiar.
- Permisos granulares por cuidador, revocables en cualquier momento.
- Acceso temporal para nanny con expiracion automatica.
- Notificaciones cuando no se cumplen metas de sueno y metas de alimentacion (onzas por dia).
